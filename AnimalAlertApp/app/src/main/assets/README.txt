==========================================
YOLOv8 Model File Location
==========================================

Place your YOLOv8 model file here:

File name: best(1).pt

Location: app/src/main/assets/best(1).pt

==========================================
Instructions:
==========================================

1. Copy your best(1).pt file to this folder
2. Make sure the filename is exactly: best(1).pt
3. The app will automatically load it when you open Camera Detection

==========================================
Note:
==========================================

- The model file will be included in the APK
- Make sure the file size is reasonable (large files increase APK size)
- The app uses PyTorch Mobile to load .pt files directly
